# Security Policy

## Reporting Security Vulnerabilities

If you discover a security vulnerability in Crawl Tester, please email rdjarbeng@rdjarbeng.com with:

- A description of the vulnerability
- Steps to reproduce the issue
- The potential impact
- Any suggested fixes (optional)

Please do not create a public GitHub issue for security vulnerabilities.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | ✅ Yes             |
| < 1.0   | ❌ No              |

## Security Practices

- Always run the crawler in a controlled environment
- Be cautious when crawling third-party websites
- Respect robots.txt and website terms of service
- Don't use this tool for unauthorized web scraping
- Keep dependencies updated: `pip install --upgrade -r requirements.txt`

## Data Privacy

- Crawl Tester does not collect or transmit any data
- All crawled content is stored locally in Markdown files
- No telemetry or tracking is performed

## Responsible Disclosure Timeline

- Day 0: Vulnerability reported
- Day 3-7: Initial acknowledgement
- Day 7-30: Fix development
- Day 30+: Public disclosure (if needed)

Thank you for helping keep Crawl Tester secure!
